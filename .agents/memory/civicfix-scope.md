---
name: CivicFix scope
description: Product scope chosen for the CivicFix artifact.
---

CivicFix is an information-only frontend preview. Keep accounts, stored reports, live community data, and AI assistance out of scope unless the user asks to add them.

**Why:** The user chose to remove the backend features rather than migrate to another provider.

**How to apply:** Preserve the informational landing page and avoid adding nonfunctional report, account, or assistant flows.
